# Stripe API Reference (Version 2020-08-27)

## Overview
The Stripe API allows developers to accept payments, manage subscriptions, and process refunds. All API requests must be authenticated using HTTP Bearer authentication with your secret API key.

## Authentication
To authenticate requests, include your secret key in the Authorization header:
```bash
curl https://api.stripe.com/v1/charges \
  -u YOUR_STRIPE_SECRET_KEY:
```

## Charges API
The Charges API is the primary method for creating credit card charges.

### Create a Charge
To charge a credit card, you create a `Charge` object using a tokenized card `source`.

```python
import stripe
stripe.api_key = "YOUR_STRIPE_SECRET_KEY"


charge = stripe.Charge.create(
    amount=2000,
    currency="usd",
    source="tok_visa",
    description="Charge for jenny.rosen@example.com",
)
```

#### Parameters:
- `amount` (integer, required): Amount intended to be collected in the smallest currency unit (e.g., 2000 for $20.00).
- `currency` (string, required): Three-letter ISO currency code (e.g., `usd`, `eur`).
- `source` (string, optional): A payment source identifier, such as a token (`tok_123`) or card ID (`card_123`).
- `description` (string, optional): An arbitrary string attached to the object.
- `capture` (boolean, optional): Whether to immediately capture the charge. Defaults to `true`.

### Refund a Charge
To refund a charge, use the `Refund` endpoint with the `charge` ID.

```python
refund = stripe.Refund.create(
    charge="ch_123456789",
)
```

## Webhooks
Configure webhook endpoints to receive events asynchronously. Verify webhooks using the `stripe.Webhook.construct_event` method with your webhook signing secret.

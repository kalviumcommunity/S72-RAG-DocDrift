# Stripe API Reference (Version 2024-04-15)

## Overview
The Stripe API (version 2024-04-15) uses the PaymentIntents API for all modern payment processing. Direct Charges via `stripe.Charge.create` are deprecated and lack Strong Customer Authentication (SCA) support.

## Authentication & API Keys
All requests must be authenticated using Secret API keys in the Authorization header. Restrict key permissions according to the principle of least privilege.
```bash
curl https://api.stripe.com/v1/payment_intents \
  -H "Authorization: Bearer YOUR_STRIPE_SECRET_KEY"
```

## PaymentIntents API
PaymentIntents represent an intent to collect payment from a customer, tracking the payment lifecycle across multiple steps including customer authentication (3DS / 3D Secure 2).

### Create a PaymentIntent
Create a `PaymentIntent` using the `payment_method_types` or `automatic_payment_methods` configuration.

```python
import stripe
stripe.api_key = "YOUR_STRIPE_SECRET_KEY"


intent = stripe.PaymentIntent.create(
    amount=2000,
    currency="usd",
    automatic_payment_methods={"enabled": True},
    description="Order #4892",
)
```

#### Parameters:
- `amount` (integer, required): Amount intended to be collected in the smallest currency unit (e.g., 2000 for $20.00).
- `currency` (string, required): Three-letter ISO currency code (e.g., `usd`, `eur`).
- `payment_method` (string, optional): ID of the PaymentMethod object to attach and confirm with.
- `automatic_payment_methods` (dict, optional): Enables dynamic payment methods including Apple Pay, Google Pay, and Klarna.
- `confirm` (boolean, optional): Set to `true` to attempt confirmation immediately upon creation.

### Breaking Changes & Deprecations from 2020-08-27:
1. `stripe.Charge.create` is deprecated; all new integrations must use `stripe.PaymentIntent.create`.
2. The `source` parameter has been replaced by `payment_method`.
3. Client-side card tokenization (`tok_123`) is replaced by Stripe Elements and PaymentMethod objects (`pm_123`).
4. Webhooks should listen for `payment_intent.succeeded` rather than `charge.succeeded`.

## Refunds API
To refund a payment in API version 2024-04-15, provide the `payment_intent` identifier:

```python
refund = stripe.Refund.create(
    payment_intent="pi_123456789",
    amount=1000, # Partial refund
)
```
